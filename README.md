# עידן ירחי — תעודת זהות (סדר ושבירה)

**תרגיל בית 1: קורס Design × AI**

עמוד Web אישי המשמש כתעודת זהות: סדר מודרניסטי שוויצרי קפדני (שחור-לבן, גריד 12 עמודות, סולם 8px, טיפוגרפיה שיטתית) מול שבירה אישית עשירה בצבע (חפצים מהחיים האישיים ברוח וינגרט וקרסון), וסירוב פעיל לטופסולוגיה המשוכפלת של הבינה המלאכותית.

---

## פתיחה מהירה

ניתן לפתוח ישירות את `index.html` בדפדפן, או להריץ שרת מקומי:

```bash
python3 -m http.server 8080
```

ולפתוח בדפדפן: [http://localhost:8080](http://localhost:8080)

---

## אינטראקטיביות ופיצ'רים מיוחדים

- **כיבוי / הדלקת גריד**: לחיצה על כפתור "כיבוי גריד" בראש העמוד או לחיצה על מקש **`G`**.
- **גרירת חפצים חופשית (Draggable Artifacts)**: כל החפצים האישיים הצבעוניים (כרטיס הופעה, צמיד נונו, כדור טניס, חותמת הקרנף, הערות) ניתנים לתפיסה וגרירה בעזרת העכבר/מגע כדי לשבש את הגריד באופן מוחשי.
- **איפוס מיקומי שבירה**: לחיצה על כפתור "איפוס שבירה" או לחיצה על מקש **`R`**.
- **צליל חבטת טניס סינתטי (Web Audio API)**: לחיצה על כדור הטניס מייצרת צליל חבטה ברשת ללא שום קובץ שמע חיצוני.
- **החתמת סירוב על הטופסולוגיה**: כפתור ייעודי בחלק הנתיחה שלאחר המוות (Autopsy) המאפשר להטביע חותמות סירוב אדומות על העיצוב הגנרי של ה-AI.
- **מד מידות חי (Live Measures)**: הקולופון בתחתית העמוד מודד ומציג בזמן אמת את ממדי החלון, ה-Viewport, יחידת הבסיס (8px) ומצב הגריד.

## מבנה הפרויקט

- [`index.html`](index.html) — עמוד ה-Web המרכזי: תעודה שוויצרית, מסת עמדה (397 מילים), פוליסת סירוב לטופסולוגיה וקולופון.
- [`styles.css`](styles.css) — מערכת הסדר (סולם 8px, שחור-לבן מודרניסטי) ושכבת השבירה הצבעונית.
- [`script.js`](script.js) — שעון, מדידה חיה, מנוע גרירה, סינתזה קולית (Web Audio) ומקשי קיצור.
- [`PROCESS.md`](PROCESS.md) — תיעוד התהליך המלא: ברירת המחדל של ה-AI, מה נפסל במודע והדיאלוג בין הסדר לשבירה.
